# LocalVoice

LocalVoice is a polished civic-tech prototype for Ottawa residents to report local issues, explore municipal resources, and better understand how city government works.

## What this prototype focuses on
- A believable, polished UI for hackathon and portfolio review
- Interactive mock flows such as saving reports, switching themes, and filling out a report form
- A clean, accessible experience that feels closer to a real product than a raw Figma export

## Tech stack
- React + TypeScript
- Vite
- Tailwind CSS
- lucide-react

## Running locally
1. Install dependencies with `pnpm install`
2. Start the dev server with `pnpm dev`
3. Open the local Vite URL shown in the terminal
